# Beyond the Mission
### The machines we left behind.

**Beyond the Mission** is a cinematic, interactive storytelling experience exploring the legacy of NASA's spacecraft and scientific equipment left behind on the Moon and Mars.

Through immersive visuals, scroll-driven animations, and curated NASA mission imagery, the project tells the stories of machines that helped humanity explore beyond Earth — and the scientific discoveries that outlasted their missions.

## 🚀 Project Overview

The project takes visitors on a journey through four chapters:

- **Deep Space** — An introduction to humanity's exploration beyond Earth.
- **The Moon** — Discover the Apollo Lunar Module descent stages, Lunar Roving Vehicles, and Apollo Lunar Surface Experiments Package (ALSEP).
- **Mars** — Explore the stories of Sojourner, Spirit, Opportunity, and InSight.
- **The Legacy** — Reflect on the engineering achievements and scientific knowledge these missions left behind.

## ✨ Features

- Cinematic, scroll-driven storytelling.
- Interactive chapter transitions and animations.
- NASA mission imagery with attribution and source links.
- Dedicated Moon and Mars exploration chapters.
- Mission timelines and historical context.
- Responsive design for desktop and mobile.
- Reduced-motion support for accessibility.

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/michaelongo/beyond-the-mission.git
```

Navigate into the project:

```bash
cd beyond-the-mission
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
